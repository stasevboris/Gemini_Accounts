# Gemini Accounts: инструкция для Windows

Программа управляет вашими аккаунтами и API-ключами и подключает доступные модели к Claude Desktop, Claude Code и Codex. Подписки, аккаунты и баланс API приобретаются отдельно. Доступ к конкретной модели определяется вашим провайдером.

## 1. Установка

1. Распакуйте полученный архив в отдельную папку.
2. Запустите `GeminiAccounts-Setup.exe` и завершите установку. Python устанавливать не нужно.
3. Откройте Gemini Accounts через созданный ярлык.
4. Для входа ChatGPT и Claude установите Firefox: эти кнопки открывают обычную вкладку браузера.

При обновлении сначала дождитесь окончания генерации в подключённых клиентах. Установщик сохраняет локальные входы и профили ключей. Не удаляйте папки данных ради обновления.

## 2. Добавление Google-аккаунтов

1. Нажмите «Добавить Google аккаунт».
2. Пройдите вход в открывшемся браузере и подтвердите разрешения.
3. Вернитесь в менеджер и дождитесь появления аккаунта и квот.
4. Повторите для остальных своих аккаунтов. Для работы со всеми включёнными аккаунтами выберите «Использовать все · автомаршрутизация».

Квоты Gemini и Claude через Google показаны отдельно. Наличие процентов не гарантирует, что любая модель доступна сейчас. Проверяйте выбранную модель и результат последнего запроса.

## 3. Добавление API-ключа

1. Откройте вкладку «API-ключи» → «Добавить API-ключ».
2. Укажите понятное название, провайдера, адрес API и свой ключ.
3. Загрузите каталог моделей либо впишите точные ID моделей, по одному на строку. Название из рекламы может отличаться от ID API.
4. Нажмите «Проверить ключ и модель», затем сохраните профиль.
5. Добавьте другие ключи таким же способом. Их модели появятся отдельно от моделей Google-подписки.

Статистика API показывает запросы, ошибки, токены и время ответа. Она не показывает баланс провайдера. Переключение между ключами возможно для включённых совместимых профилей с тем же адресом API и точным ID модели, до передачи содержимого ответа. Его можно отключить в редакторе ключа.

## 4. Аккаунты ChatGPT

1. Откройте вкладку «ChatGPT» → «Добавить аккаунт ChatGPT».
2. Завершите вход во вкладке Firefox и дождитесь подтверждения в менеджере.
3. Для другого аккаунта выберите другой вход ChatGPT в браузере и повторите процедуру.
4. Альтернатива — «Импортировать auth.json»: вручную выберите файл входа Codex, содержащий именно авторизацию ChatGPT. Файл автоматически не копируется из вашей текущей установки Codex.

Менеджер использует отдельный пул аккаунтов ChatGPT. Квоты и приоритеты Google не определяют доступность GPT. Опция сброса квот, если её предоставил провайдер, требует подтверждения и может расходовать доступный сброс.

## 5. Собственные аккаунты Claude

1. Откройте вкладку «Claude» → «Добавить аккаунт Claude».
2. Авторизуйтесь своим аккаунтом во вкладке Firefox. Доступ через подписку должен быть разрешён для вашего аккаунта.
3. Дождитесь автоматического возврата. Если он не сработал, вставьте полученный код или адрес возврата в окно входа и нажмите «Завершить вход по коду».
4. Можно импортировать вручную выбранный JSON входа Claude: экспорт шлюза либо файл Claude Code с полным OAuth-входом. Файлы других приложений автоматически не импортируются.
5. Кнопка «Проверить отклик» отправляет небольшой запрос именно через выбранный аккаунт. Такой тест расходует небольшую часть квоты.

Аккаунты подписки Claude образуют отдельный пул. Их модели в клиенте помечены `Claude subscription`. Это отдельный источник от Claude через Google и Claude через API-ключ. Данные квот кэшируются на 5 минут. Отдельный недельный лимит Opus или Sonnet не означает исчерпание всех моделей аккаунта.

Поддержка ChatGPT и Claude добавлена в этой сборке и проверена автоматическими тестами. Успешный вход и генерацию на своих аккаунтах нужно проверить отдельно: ограничения провайдера и изменение его интерфейсов могут повлиять на доступ.

## 6. Подключение клиента и выбор модели

1. Установите нужный клиент: Claude Desktop, Claude Code CLI либо Codex.
2. Нажмите в менеджере «Подключить приложения», выберите клиент и подтвердите предлагаемые изменения его настроек.
3. Дождитесь окончания текущей работы и переоткройте клиент, чтобы он загрузил обновлённые настройки и список моделей.
4. В Claude Desktop используйте вкладку Code с настроенным локальным пресетом. Обычный веб-чат Claude — отдельное подключение.
5. Выберите модель по её источнику и отправьте пробный запрос: «Напиши Python-функцию, которая удаляет дубликаты из списка, сохраняя порядок. Добавь три примера».

Примеры обозначений источника:

- `Gemini · …` — Google-аккаунты.
- `Claude · …` — Claude через Google.
- `API · Название профиля · …` — ваш API-ключ.
- `ChatGPT · …` — аккаунты ChatGPT.
- `Claude subscription · …` — собственные аккаунты подписки Claude.

Переключать модель можно в текущем диалоге, если клиент передаёт новой модели историю. Менеджер сам не переносит чаты между отдельными приложениями. При смене источника накопленная история отправляется выбранному провайдеру; поддержка вложений и инструментов зависит от модели и клиента.

## 7. Ежедневная работа

- Оставляйте менеджер открытым для мониторинга и автоматической маршрутизации.
- Не закрывайте клиент во время активной генерации, если хотите получить ответ.
- Приостановленный аккаунт не участвует в автоматическом выборе.
- Удаление аккаунта из менеджера удаляет локальный сохранённый вход, а не сам аккаунт у провайдера.
- В настройках списка можно скрыть имена аккаунтов перед созданием скриншотов.

## 8. Частые ошибки

**429 / Rate limit.** Провайдер ограничил частоту запросов или квоту. Посмотрите последнее событие и время сброса. Наличие другого аккаунта помогает только при доступности той же модели у него.

**401.** Авторизация или API-ключ недействительны. Проверьте ключ либо войдите в аккаунт повторно.

**402.** Провайдер отказал по условиям оплаты. Проверьте баланс и доступ к выбранной модели на его стороне.

**403.** Провайдер отказал в доступе. Проверьте разрешения, верификацию аккаунта и доступность модели.

**502 / 503.** Временная ошибка провайдера или локального сервиса. Посмотрите журнал и повторите запрос после устранения причины.

**Ключ сохранён, но модели нет в клиенте.** Проверьте, что профиль включён и точный ID модели сохранён; затем обновите подключение и переоткройте клиент после окончания генерации.

**Квоты не отображаются.** У провайдера могут отсутствовать данные либо действовать ограничение их чтения. Программа не подставляет выдуманные проценты. Проверяйте фактический отклик.

**Firefox не найден.** Установите Firefox и нажмите кнопку входа заново.

**«Local connection returned error».** Проверьте, что менеджер и локальные сервисы запущены. Не удаляйте сохранённые аккаунты и не сбрасывайте данные до диагностики.

## Ссылки и поиск в Claude Desktop

Можно отправить модели ссылку с просьбой прочитать страницу или дать задачу найти информацию в интернете. Профиль подключения разрешает доступ к сайтам. Если вы вручную задали список разрешённых хостов, программа сохраняет его.

Для моделей без встроенного поиска отдельный вызов WebSearch выполняет доступная Gemini или ChatGPT-модель; результаты возвращаются основной модели в текущем чате. Для этого нужен подключённый и доступный Google- или ChatGPT-аккаунт. Поиск может расходовать его квоту.

После обновления со старым профилем создайте новый чат Desktop: существующие сеансы сохраняют прежние сетевые настройки. Поиск не даёт доступ к содержимому сайтов, требующих вашего входа, и сайты могут отклонять автоматическое чтение.

## 9. Данные, восстановление и обращение за помощью

На Windows данные находятся в `%LOCALAPPDATA%\GeminiAccounts` и `%LOCALAPPDATA%\ClaudeGemini`. Сохранённые входы, API-ключи и полные резервные копии содержат секреты. Не прикладывайте их к публичным сообщениям и объявлениям. Пароли и API-ключи не нужно отправлять продавцу в чат.

Перед изменением клиентских настроек менеджер сохраняет копии. «Подключить приложения → Восстановить прежние настройки» возвращает сохранённые конфигурации. Более поздние ручные изменения клиента при этом могут замениться.

Для помощи подготовьте версию программы, название клиента, источник и ID модели, время ошибки и её код. На скриншотах скройте почту, ключи и личную переписку. Диагностические архивы отправляйте только после проверки их содержимого.

Если куплен пакет с настройкой, согласуйте помощь в чате FunPay. Пакет со сборкой и инструкцией предполагает самостоятельную установку. Программа с открытым исходным кодом; состав и срок поддержки определяются описанием вашего заказа.

## Приоритет, резерв и компактный вид

Счётчик ↑ в карточке задаёт приоритет 0–999: большее число используется первым среди доступных аккаунтов. Одинаковые значения оставляют автоматический порядок. Ограниченный аккаунт не становится доступным из-за высокого приоритета.

На полосках квот перетащите тонкий маркер; двойной щелчок позволяет ввести процент. Резерв 20% означает остановку новых запросов при остатке 20%, а не расход только 20%. Значение 0% снимает резерв. Настройки сохраняются отдельно для аккаунта, семейства моделей и периода. При отсутствующих данных настроенный резерв удерживается до обновления; уже запущенный ответ может пересечь границу. Резерв не включает платное использование.

Нажмите стрелку у списка или общей квоты, чтобы свернуть раздел. Индикаторы останутся видны: серый означает отсутствие данных, красный — нулевой остаток. Шестерёнка в шапке доступна и в мини-окне: там язык, тема, приватность и видимость сервисов. Скрытие меняет отображение; подключения и обновление квот продолжают работать.

## Grok, оценки токенов и уведомления

На вкладке **Grok** нажмите **Добавить аккаунт Grok**, откройте страницу xAI и подтвердите показанный код. Программа ждёт завершения входа; отмена закрывает только эту сессию авторизации. Модели берутся из подключённого аккаунта. Если провайдер не сообщает квоты, полоски процентов не рисуются.

В **Статистике маршрутизации** калькулятор оценивает количество токенов для выбранной доли квоты. После трёх корректных замеров появляется приблизительный результат. Ниже прогнозируется время до резерва и сравнивается со временем сброса. Прогноз зависит от текущей нагрузки и не обещает доступный бюджет. Старые запросы при запуске не считаются новым расходом.

В настройках отображения можно отдельно включить уведомления о необходимости повторного входа и достижении резерва. Опрос одного и того же состояния не повторяет уведомление. Строка времени авторизации показывает наблюдаемую доступность учётных данных; пауза и сетевой сбой не выключают аккаунт.

Для входа Google через другой профиль браузера скопируйте ссылку из окна входа. Если браузер заблокировал локальный переход, вставьте полный адрес callback в этом же окне. После ошибки адреса можно повторить попытку, не создавая новый вход.

## Компактное меню моделей Claude

В разделе Google остаются Opus/Sonnet без дублей и Flash 3.8 High, Medium, Low. Другие поколения Flash/Pro/Lite и Google Haiku скрыты из этого меню. GPT и подключённые API-модели и провайдеры показываются отдельно. Штатный список Claude Code требует версии 2.1.242 или новее. Обновите конфигурацию подключённого клиента и перезапустите его после завершения текущей работы. Для Opus/Sonnet сохраняется выбор усилия в клиенте; у Flash уровни представлены отдельными ID моделей. Маршруты существующих чатов сохраняются.
