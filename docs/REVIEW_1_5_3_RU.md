# Ревью Gemini Accounts 1.5.3

Проверены UI, клиентские конфигурации, шлюз API, закрепление аккаунтов, роли и проверки команды, ограничения инструментов и установка обновлений.

## Исправления

1. Удалены вкладки Grok/Kimi, их выбор для команды и подключение OpenCode. Управляемые старые модели удаляются из конфигураций Claude и списка моделей шлюза. Пользовательские алиасы и файлы авторизации сохраняются.
2. HTTP 429 больше не считается доказательством законченных токенов: частота и число одновременных запросов показываются отдельно. Исчерпание определяется по HTTP 402 и явным сообщениям провайдера о квоте/балансе.
3. API-профили переключаются в пределах того же адреса API, протокола и точного ID модели. Каждый ключ пробуется один раз в запросе до передачи ответа. Переключение можно отключить в карточке профиля.
4. Ограниченный профиль временно исключается из следующих запросов. Статус и время повторной попытки сохраняются после перезапуска. Смена ключа или сервера снимает старое ограничение; новый запрос после паузы может повторить проверку.
5. Ошибка `auth_unavailable` с подтверждённой перегрузкой сохраняет временные повторы. Ошибка без временной причины или HTTP 401/402/403 прекращает повторы этого аккаунта в текущем запуске и показывает причину.
6. После использования инструментальных шагов агент получает завершающий ход без инструментов, чтобы вернуть предложения и незавершённые пункты. Общие ограничения времени и запросов сохраняются.
7. Координатор получает явное описание прав: исполнители и проверяющие читают и предлагают изменения, координатор применяет одобренные изменения и запускает разрешённые проверки. Путь проекта и разрешения включены в инструкции.
8. При ошибке проверяющего используется другой независимый аккаунт. Одобрение сбрасывается перед исправлением результата, чтобы не применять устаревшую проверку.
9. Установщик проверяет активную команду даже при ручном обновлении.

## Проверка

- 347 автоматических тестов прошли в сборочном окружении, включая новые проверки классификации 429, ротации между запросами, восстановления после паузы, смены ключа и резервного проверяющего.
- Содержимое 44 упакованных модулей совпало с исходниками, четыре исполняемых файла установщика совпали с payload.
- Установлена версия 1.5.3; локальный шлюз, нативная служба и MCP-подключения Claude Desktop/Claude Code проверены.
- Сохранены 22 OAuth-аккаунта и три API-профиля. API-ключи и локальные ключи не изменялись; четыре OAuth-файла обновили только токены и поля времени при штатном обновлении авторизации.
- Сохранён состав из восьми Google-аккаунтов: координатор, пять исполнителей и два проверяющих. Лимит шагов увеличен с 12 до 24, число повторов уменьшено с трёх до двух; параллельность 4 и пользовательские разрешения сохранены.
- Живая проверка на трёх Google-аккаунтах завершилась успешно за 14 запросов: предложение исполнителя, независимая проверка, запись координатором `agent-smoke.txt` и чтение результата. Содержимое подтверждено локально; временные маршруты восстановлены, сохранённый состав не изменён.

## Практические границы

Остаток токенов API не вычисляется из счётчика использованных токенов. Отображается подтверждённая провайдером причина отказа; 429 без такой причины остаётся временным ограничением. Аккаунты команды закреплены за выбранными участниками, а автоматическая ротация касается совместимых API-профилей.
