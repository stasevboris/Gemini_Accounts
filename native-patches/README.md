# Исправление входа Google

CLIProxyAPI 8.0.16 использует порт 51121 для возврата из Google. Windows может
зарезервировать этот порт: тогда `/antigravity-auth-url?is_webui=true` возвращает
HTTP 500 `failed to start callback server`, хотя порт не занят процессом.

Патч сохраняет стандартный порт, когда он доступен. Если открыть его невозможно,
он держит listener на свободном порте loopback. Этот фактический порт используется
и в ссылке Google, и при обмене кода авторизации на токены. Настройки Windows,
аккаунты, API моделей и маршрутизация не меняются.

Исходники: официальный тег v8.0.16, commit указан в `manifest.json`.
Изменения и проверки находятся в `callback-port.patch`. Сборка остаётся локальной
версией `8.0.16+callbackfix1`; контрольные суммы записаны в манифесте.

Для повторной сборки из корня проекта:

```powershell
.\native-patches\build.ps1 -Python .\.venv-pyside6\Scripts\python.exe
.\build-release.ps1 -Python .\.venv-pyside6\Scripts\python.exe
```

`build-release.ps1` проверяет checksum и включает исправленный прокси в установщик.
При отсутствии исправленного бинарника сборка останавливается с инструкцией
пересобрать его, чтобы обновление случайно не вернуло ошибку входа.
